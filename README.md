# Dynamic Task Manager

A React-based task management application built with React and Vite.

## Features

- Add new tasks
- Prevent empty tasks
- Complete and uncomplete tasks
- Delete individual tasks
- Filter tasks by All, Completed, and Not Completed
- View total and completed task statistics
- Clear completed tasks
- Responsive design

## Technologies

- React
- JavaScript
- JSX
- CSS
- Vite

## How to Run

```bash
npm install
npm run dev
